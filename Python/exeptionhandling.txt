1. What is Exception Handling?
Exception handling is a programming technique used to detect and manage errors that occur while a program is 
running. Instead of crashing, the program can handle the error gracefully and continue executing.

Common Exceptions in Python
ZeroDivisionError
Occurs when dividing by zero.
ValueError
Occurs when an invalid value is passed to a function.
TypeError
Occurs when an operation is performed on incompatible data types.
IndexError
Occurs when accessing an invalid list index.
KeyError
Occurs when accessing a dictionary key that doesn't exist.
FileNotFoundError
Occurs when a file cannot be found.
NameError
Occurs when using a variable that has not been defined.

2. The try and except Statement
The try block contains code that may cause an exception. If an exception occurs, Python executes the except block.
Syntax
try:
    # Code that may cause an exception
except ExceptionType:
    # Code to handle the exception
